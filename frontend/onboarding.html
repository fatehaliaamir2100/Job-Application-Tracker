Step 2 of 3

Get Gmail credentials

Create a Google Cloud OAuth client so this app can read your Gmail.

  1. 01 Go to Google Cloud Console and create a new project
  2. 02 Enable the Gmail API for your project
  3. 03 Go to Credentials → Create Credentials → OAuth client ID
  4. 04 Choose Desktop app as the application type
  5. 05 Download the JSON file — it will be named credentials.json
  6. 06 Under OAuth consent screen, add your Gmail address as a test user
